# NoteMenu 深色模式设计 V1

沿用已确认的浅色 V2：相同的布局、字号、间距、控件尺寸和交互，同样展示待输入与编辑中两种状态。标题前直接使用本 App 图标，保留原始黄色与米白色，不反色。

## 设计理念

- **用深灰层次区分区域。** 编辑区采用炭灰，标题栏和工具栏略亮。细描边补充暗背景下的窗口边界，不依赖强阴影或发光效果。
- **保持舒适的文字对比。** 正文使用柔和灰白，辅助图标和目录名称再降低一级亮度。提示文字保留清晰可辨的对比度，不使用纯白正文配纯黑背景。
- **控制黄色的面积与亮度。** 保存按钮略微收敛亮度；Hover 使用深琥珀底；格式选中态仅使用金黄色前景，不保留背景。应用图标保持原样，继续作为品牌识别点。

## 交互补充

- 浅色、深色可跟随系统外观切换；不新增窗口内主题开关。
- Pin 和列表选中态只显示金黄色前景；Hover 才显示深琥珀背景。格式入口在中英文中均固定显示 Aa。
- 空稿保存为灰色禁用态，输入后点亮黄色；等待动画和保存成功提示沿用既有位置和行为。
- 原生目录菜单与 Tooltip 跟随系统外观，文本选择继续使用系统选区色。
