# Tips V3 实现与验收

## 实现

- 顶部浮层统一承载普通提示与功能提示，分别使用 `info.circle`、`lightbulb`。默认 2 秒，普通提示可传入自定义时长。
- 顶部卡片恢复单行 40pt，两行按文本高度自适应并保留上下留白；关闭按钮为 12pt 标题栏同色实心圆，6pt 次要文字色 ×，Hover 时改为格式按钮同款浅黄背景与强调色前景。左图标靠左绘制，左右端内间距统一为 10pt，关闭命中区同步布局。
- 保留标题栏下方 8pt、最大宽度 300pt、暖色毛玻璃及深浅色适配；提示不参与正文排版，主体点击穿透，关闭按钮独立响应。
- 编辑器发布 `keyPress`、`afterKeyPress`、`keyRelease`、`beforeInput`、`afterInput`、`enterFormat`、`leaveFormat`，以及会话、选区、鼠标辅助事件。规则层独立判断触发与习得，调度层只负责展示。
- 代码格式进入时触发；只有当前 ↓ 操作真正离开代码才习得。按键上下文仅在当前事件有效，菜单操作不会继承旧按键。
- 多级全选在 `afterKeyPress` 读取本次 ⌘A 的实际结果：第一级且还有上层可选时提示，第二级及以上时习得。移除提示层的连按标记；菜单产生的第一级同样适用。无有效结果、单层内容、自动重复均不触发。
- 缩进用真实格式切换事件及当前按键判断习得；标题语法只根据实际成功的语法转换结果记录习得，不再缓存操作前格式。提示规则层只持有调度器引用，不维护操作历史。
- 每种未习得功能每次应用启动最多显示一次；删除每日／累计次数／冷却限制。点击关闭不记录习得。展示记录只保存在应用持有的控制器内存中，关闭／重开窗口、新建草稿、切换提示开关都不重置；退出重启才重新获得额度。
- 窗口呼起只同步当前格式基线，不补发 `enterFormat`。恢复原光标不会触发列表／代码提示；真实格式切换仍需通过当前应用启动周期的额度检查。
- 标题提示改为订阅模型的 `draftCreated`（`onDraftCreate`）：首次无草稿时呼起创建一次，成功保存／明确清空后创建下一篇。恢复草稿、反复呼起、删除全部文字、切换标题格式不触发。用语法成功创建标题仍直接习得。模型独立记录草稿是否存在，避免将空正文误当成不存在草稿；沿用现有空白无格式草稿不落盘行为。
- 使用独立 `tips.v3.learned.<id>` 学习记录，避免旧版将关闭提示误认为学习完成的数据影响调试。
- 功能开关不影响普通提示和保存快捷键。保存按钮保持自定义 Hover 提示，格式按钮不增加说明气泡。

- 首次启动自动弹窗时优先入队普通欢迎提示，产品名取自应用信息；2 秒后按队列显示功能提示。使用独立持久标记 `didShowFirstLaunchEditor`，验证欢迎优先、按时切换及窗口重开不重播。

## 连续触发与竞态

主线程维护唯一展示槽位。不同提示 FIFO 排队，相同 ID 在队列和可见状态去重，不延长当前提示计时。普通输入、中文组合、换行、选区、滚动及习得操作都不缩短已经显示的 2 秒。

每次展示／取消使用新的代次，旧延迟回调不能关闭新提示。离开适用格式、习得和关闭窗口会删除相应待显示请求。保存快捷键主动查看可替换顶部提示；菜单、保存、失焦等明确界面切换可提前收起。其余有效请求在解除阻塞后继续。

新提示在组合输入、鼠标按住时等待；编辑状态变更及鼠标释放后重试。嵌套菜单计数独立，不会错误解除外层菜单或保存阻塞。

人工验收建议：在新呼起周期内进入代码块、再进入列表，确认各自能提示；关闭窗口后再次进入代码块，确认不重复提示；退出重启后实际进入代码块，确认未习得时可再次提示；用 ↓ 离开代码块后重新呼起，确认对应提示停止。另在多段笔记中第一次 ⌘A 查看提示，第二次连续 ⌘A 扩选并习得。
