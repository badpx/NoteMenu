# NoteMenu Tips 设计规范 V3

状态：已实现。V3 保留标题栏下方毛玻璃浮层，简化触发和学习策略；本规范取代 V2 系列的频控、闲置触发、选区避让和关闭即习得规则。验收见 [实现与验收](tips-implementation.md)。

## 1. 提示类型

| 类型 | 用途与入口 | 图标 | 限制 |
|---|---|---|---|
| 普通提示 | 调用 `showInformation(id:message:duration:)` 按需展示 | `info.circle` | 默认 2 秒，可指定时长；不记录习得，不受功能提示开关限制 |
| 功能提示 | 编辑器 hook 触发，通过 `showFeature(_:)` 展示 | `lightbulb` | 未习得之前，每种提示每次应用启动最多显示一次；默认 2 秒 |
| 保存快捷键 | 保存按钮 Hover／键盘聚焦 | 文案和快捷键按键块 | 150ms 后显示，2 秒收起；移出再移入可重看 |
| 保存反馈 | 标题栏已有状态区 | 保存中等待动画 | 保存中持续至结果返回，成功文字显示 2 秒；错误继续用明确弹窗 |

首次自动弹出输入窗口时，优先显示普通欢迎提示：“你好，欢迎使用${产品名}，\n你可随时记录想法并保存至系统备忘录。”英文为 “Welcome to ${productName}.\nCapture ideas and save to Apple Notes.” 产品名从应用信息读取，默认 NoteMenu。欢迎提示先入队，默认 2 秒后再显示草稿创建等功能提示。首次启动标记 `didShowFirstLaunchEditor` 持久保存，后续启动不自动弹窗或重复欢迎。

普通提示与功能提示共用顶部浮层。普通提示用于简短信息，不替代需要用户处理的错误。格式、图片、目录、Pin、关闭按钮不显示可视 Tooltip，保留辅助功能名称和状态。

## 2. 位置、视觉与交互

- 顶部浮层位于标题栏下方 8pt，编辑区水平居中，宽度不超过 300pt；窄窗口两侧至少 16pt，最多两行。宽窗口不把提示拉长。
- 圆角 8pt；正文字号 12pt Regular，行间距 3pt；左右内边距 10pt，左图标与文字间距 10pt，文字与关闭按钮间距 6pt；单行高度 40pt，两行按文本高度增加容纳空间，保留上下各 8pt 留白。
- 结构：12pt 类型图标、一条简短消息、关闭按钮。左图标靠左绘制，左图标与关闭按钮距各自边缘均为 10pt。关闭按钮直径 12pt，× 图形 6pt；默认圆形背景复用标题栏背景色（浅色 #FAFAF8／深色 #28292A），前景使用次要文字色；Hover／按下时背景复用格式按钮 Hover 色（浅色 #FFF0B8／深色 #494027），前景使用强调色。圆形命中区与显示尺寸一致。
- 使用窗口内毛玻璃，叠加暖色染色；文字、图标、关闭按钮完全不透明。减少透明度时回退实色背景。
- 不参与正文排版，不改变窗口尺寸、正文起点、滚动位置或选区。不抢焦点，不向文档写入提示内容。
- **允许与当前光标或选区相交**，以支持进入格式后立即提示和首次 ⌘A 后提示。提示主体点击穿透，只有关闭按钮接收点击。
- 淡入淡出约 120ms，无位移／缩放；遵循减少动态效果设置。

| 元素 | 浅色 | 深色 |
|---|---|---|
| 背景染色 | #FFF8DE，65% | #302C21，70% |
| 正文 | #5C4A21 | #E6D9B5 |
| 图标 | 使用界面强调前景色 | 使用界面强调前景色 |
| 细描边 | #E8DCA8 | #51462A |

保存快捷键浮层仍位于保存按钮上方 6pt，右边缘对齐；圆角 8pt，字号 12pt，内边距横向 10pt／纵向 6pt，无箭头。文案为“存至备忘录　⌘ ↩”／“Save to Notes　⌘ ↩”。空稿与保存中不显示。

## 3. 展示生命周期

1. 事件触发后进入队列，在下一轮主线程调度中检查可展示条件；不再等待 1.5 秒输入闲置。
2. 窗口需要可见、处于激活状态、编辑器可编辑、空间足够。输入法组合、鼠标按住、菜单或弹窗期间暂缓新提示；条件解除后再检查。鼠标释放也会触发检查。
3. 每条提示从实际出现时开始计时，默认 2 秒。输入、中文组合、换行、选区、滚动、鼠标悬停及习得动作不改变已显示提示的截止时间。
4. 点击 × 或 Esc 只关闭当前提示，**不代表已习得**；关闭后当前应用启动周期内同种功能提示不重弹。
5. 窗口关闭、失焦、调整尺寸、开始保存、打开菜单等明确的界面切换可提前收起。Esc 在输入法候选或弹窗期间交给相应界面处理。
6. 关闭窗口清理队列和计时器；重新呼起保留每种功能提示的展示记录，不补发当前格式的进入事件。光标仍在原列表／代码块时不自动弹出；需要实际切入该格式才能触发。仅退出并重新启动应用才重置这个额度，失焦、关闭窗口、新建草稿和开关小贴士均不重置。
7. 普通提示的同一 ID 在显示／排队期间去重，不重置时长；结束后可再次触发。不同 ID 按顺序展示。

## 4. 频次与习得

- **每种未习得功能提示，每次应用启动最多显示一次。** 各功能独立限次，记录只保存在本次进程内存中，不写入磁盘。
- **不设每日上限、累计次数上限或跨提示冷却时间。** 应用启动周期内的限次独立生效。
- 额度在实际显示时消耗。排队但尚未显示不算；进入组合状态后延迟的请求也不算已展示。
- 习得由真实操作判定；习得后本地持久化，以后的窗口周期不再自动显示对应功能提示。
- 已显示提示在习得时仍保留原定阅读时间；尚在队列中的同种提示立即删除。
- 右键菜单“显示编辑小贴士 / Show Editing Tips”只控制功能提示，普通提示、保存快捷键和保存结果不受影响。
- V3 使用 `tips.v3.learned.<id>`，不继承旧版将“关闭提示”混同于“已习得”的记录，也不读取旧展示次数。升级后功能提示可能重新出现；新记录只由学习操作生成。

## 5. 编辑器 hooks

编辑器发布操作事实，功能提示模块订阅事件；展示调度器不参与文档编辑。

| Hook | 时机 |
|---|---|
| `keyPress` | 编辑器处理按键之前；包含当前按键、修饰键、重复标记及实际布局字符 |
| `afterKeyPress` | 本次按键处理完成后；Context 反映实际执行后的选区层级，保留本次按键信息 |
| `keyRelease` | 编辑器收到按键释放时 |
| `beforeInput` | 原生输入或编辑命令修改状态之前；嵌套编辑合并为外层事件 |
| `afterInput` | 实际改变状态后；包含提交后的格式和选区，空操作不作为学习依据 |
| `markdownShortcutApplied` | 成功执行输入语法转换后，携带实际完成的转换结果，用于直接记录语法习得 |
| `enterFormat` | 光标所在段落的格式实际发生切换后，报告新格式；窗口呼起只同步格式基线，不发送此事件 |
| `leaveFormat` | 切换前的格式作为事件参数，Context 为切换后的实际状态 |
| `selectionChanged` | 选区更新后，可清理与当前操作不再相关的待显示请求 |
| `pointerPress` | 窗口内鼠标按下，可清理与当前操作不再相关的待显示请求 |
| `sessionStarted` | 每次输入窗口呼起，仅重置临时判断状态，不直接触发功能提示 |
| `draftCreated`（`onDraftCreate`） | 模型首次创建草稿，或保存成功／明确清空后创建下一篇草稿；恢复已有草稿、删除全部文字和重新呼起不属于创建 |

Context 包含当前按键、格式、选区、文档版本、组合输入状态、空稿状态及已完成的全选层级／可用层级数。格式来自编辑模型，不通过提示模块猜测输入文本。

按键 Context **只在本次按键处理期间有效**。菜单／鼠标操作不会继承很早之前按过的 ↓，避免错误习得。Hook 为只读观察；订阅方不可在回调里同步改写文档。订阅返回可移除的 token。

## 6. 首批功能规则

| ID | 触发事件 | 习得条件 | 中文提示 |
|---|---|---|---|
| `format.heading` | `draftCreated`：首次呼起且无已有草稿，或明确创建下一篇草稿 | `markdownShortcutApplied` 确认标题语法转换成功，不根据当前格式或按键历史推断；成功用语法创建时直接习得，删除待显示提示 | 行首输入 # 再按空格，可创建标题。 |
| `list.indent` | `enterFormat` 进入未达最大深度的列表 | `leaveFormat` 确认本次 Tab／⇧Tab 操作实际离开原列表格式（改变层级或退出列表） | 列表中按 Tab 可增加缩进。 |
| `code.exit` | `enterFormat` 进入代码格式 | `leaveFormat` 离开代码，且本次 Context 的按键是无修饰键 ↓ | 在代码块最后一行按 ↓，可回到正文。 |
| `selection.expand` | ⌘A 的 `afterKeyPress`：实际结果为第一级且仍有更高层可选 | 同一事件的实际结果为第二级及以上；先判习得再判提示，不需要连续按键历史 | 再次按 ⌘A 可扩大选区，直到选中整篇笔记。 |

对应英文：

- Start a line with # and a space to create a heading.
- Press Tab to indent a list item.
- Press ↓ on the last line of a code block to return to body text.
- Press ⌘A again to expand the selection to the whole note.

实际全选层级由现有编辑器计算，可能是两级或三级；只有一层时不提示扩展。提示模块不记录前一次按键、连按标记或操作前格式。鼠标／输入实际改变选区时，由编辑器自己的选择逻辑决定下一次选择层级；单纯收到其他事件不再否定有效结果。即使第一级由菜单全选完成，接下来 ⌘A 产生第二级也可直接习得。长按产生的自动重复仍不用于教学或习得；没有有效选择结果时不作判断。快速扩展到第二级、提示尚未显示时，记录习得并删除请求，避免闪现。

离开代码／列表时移除尚未显示的相应请求；已显示的提示继续原定计时。代码块内部换行或移动仍属同一格式，不算离开或习得。用菜单改回正文不算学会 ↓。标题提示不再订阅格式进入事件；首次呼起创建草稿时触发，同一份空稿、删空后的草稿以及已恢复草稿重新呼起均不重发创建事件。保存失败或保存期间发生新编辑而保留原草稿时，不创建下一篇。保存成功创建下一篇仍遵守当前应用启动周期的展示上限与习得记录。

草稿存在性由模型维护，不以是否有文字判断。当前空白无格式草稿不落盘，应用退出后若无可恢复草稿，下次首次呼起会创建新草稿；同一次应用运行中的反复开关窗口不会重复创建。

## 7. 队列与竞态

- 主线程管理单一展示槽位；不同普通／功能提示按触发顺序排队。后来的请求不覆盖当前阅读时间。
- 相同提示 ID 去重；失效场景、已习得、关闭窗口时删除相应请求，不播报旧会话的内容。
- 每次展示、取消或替换递增代次；延迟显示和到时收起均检查代次。旧回调不得收起新提示。
- 保存快捷键属于主动查看，允许优先替换当前顶部提示；菜单和保存状态优先于提示。已被中断的提示不重播，其余仍有效的排队请求在阻塞解除后继续。
- 保存悬停每次只触发一次；移出取消尚未展示的任务，再移入才可开始新一轮。
- 嵌套菜单单独计数，不得在子菜单关闭时错误解除外层菜单或保存阻塞。

## 8. 扩展方式

新增功能提示时：

1. 在 `EditorTip` 声明稳定 ID、中英文消息，默认作为功能提示使用灯泡图标。
2. 在 `EditorFeatureTips` 中订阅已有 hook，分别定义触发事件与真实习得条件。
3. 如需短暂流程状态，保存在规则层，并在 `sessionStarted` 重置；不加到文档或草稿模型。
4. 添加覆盖触发、习得、误触发及连续触发的测试。无需为每个新功能修改窗口或计时器。

普通提示直接调用 `model.tips.showInformation(id: "stable.notice.id", message: "简短提示")`，可按需传 `duration`。消息应保持一至两行；同一事件使用稳定 ID 避免短时间重复入队。

## 9. 验收与视觉参考

- 验证每种功能独立按应用启动周期限次；关闭后重新呼起或实际重新进入格式都不能重置额度，退出并重新启动后未习得功能才重新获得展示机会；习得后持久停止，旧频控键不生效。
- 验证代码提示在进入格式后触发，↓ 真正离开才学习；菜单切换、代码内移动不会误学。
- 验证真实 ⌘A 两级／三级选择、快速连按、按键释放、鼠标／其他键打断和自动重复。
- 验证普通提示不同图标、独立时长、同 ID 去重和功能开关隔离。
- 验证队列、旧计时器、嵌套菜单、输入法、鼠标按住后释放、关闭／重新呼起竞态。
- 生产 SwiftUI 组件检查深浅色、中英文、窄窗／宽窗，提示显示前后内容、选区、布局和滚动位置不变；主体点击穿透，关闭按钮独立响应。
