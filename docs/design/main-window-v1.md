# NoteMenu 主窗口设计 V1

设计方向：**一张随时展开的轻便便笺**。保留标题栏、编辑区、底部工具栏三段结构，让文字成为视觉主体；通过留白、控件对齐、表面层次和统一强调色提升完成度。

这是一版视觉提案，尚未修改应用实现。设计稿展示同一方案的待输入和编辑中两种状态。生成图用于表达视觉方向，以下尺寸和状态说明作为后续实现依据。

## 设计理念

1. **保留入口感。** 不增加笔记列表、侧栏或导航。呼起后即可输入，底部明确选择保存位置并存入系统备忘录。
2. **让边框退后，让文字靠前。** 编辑区保持纯白；标题栏和底栏以极浅暖灰区分，分隔线降到低对比度。窗口外只保留轻边线和柔和阴影，不让工具栏像两条厚重边框夹住内容。
3. **用秩序改善精致度。** 五个格式按钮使用相同热区和中心间距；标题与内容起点对齐。文件夹图标、名称和展开箭头形成一个完整控件，明确保留左右内边距。
4. **黄色只表达身份与动作。** 小型品牌标识、选中状态、光标、保存按钮使用同一黄色体系。普通图标使用中性灰，目标目录不再单独使用蓝色抢夺注意力。
5. **空白也是正常工作状态。** 空稿只留一行提示，不增加引导卡片或占位插画；保存不可用时使用浅灰，有内容时才点亮黄色。

## 状态与交互

- 普通工具按钮与目录选择器默认无底色，Hover 出现淡黄色圆角背景；列表或 Pin 选中时仅前景图标改为强调色，不显示常驻背景。格式入口始终显示字面文字 Aa，不使用随语言变化的系统 textformat 符号。
- 空草稿的保存按钮使用灰色禁用态；有内容时为黄色，Hover 加深。Tooltip 继续提示“存至备忘录(⌘ + Enter)”。
- 目录按钮维持当前位置和菜单行为，不改变目标目录选择逻辑。
- 保存期间继续使用标题旁的等待动画；成功后继续在标题栏居中短暂提示“已保存至系统备忘录”，保留标题、保持浮窗打开。
- 拖动标题栏、记忆位置、快捷键、富文本输入和图片插入等已有交互保持当前约定。
