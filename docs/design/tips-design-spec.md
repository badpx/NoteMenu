# NotesMate Tips 设计规范

状态：设计提案，尚未实现。当前优先设计输入窗口内的提示；菜单栏技巧页留作后续方案，暂不改动。适用于功能发现、快捷键教学和操作结果反馈；具体提示是否上线仍按功能价值逐条评审。

当前重点的[输入窗口提示效果图](tips-editor-states-v2.png)展示首次空白、保存中、保存成功三个独立状态。保存成功示例按现有行为展示清空后的草稿。此前的[菜单栏技巧页概念图](tips-effect-v1.png)仅供后续参考。

## 1. 设计边界

NotesMate 是菜单栏快速记录工具，主界面为可移动、可缩放的单一输入浮窗。当前默认尺寸为 **380 × 410pt**，最小尺寸为 **360 × 200pt**；标题栏高 40pt、底栏高 48pt。标题栏已有保存进度和保存成功提示，工具栏控件已有悬停帮助，保存或权限失败使用系统对话框。空白编辑区遵循[主窗口设计](main-window-v1.md)的“一行输入提示”约定。

**核心规则：让用户随时能直接写字。** 自动出现的 Tips 只能使用窗口的非编辑区域；不得覆盖正文、选区、光标、输入法候选窗，也不得改变编辑器焦点或滚动位置。更长的说明由用户主动打开。

Apple 的设计指南建议在当前情境提供简短帮助、让反馈强度匹配事件重要性，并谨慎使用会打断工作的警告框。本规范把这些原则落到 NotesMate 的单浮窗结构中：[提供帮助](https://developer.apple.com/design/human-interface-guidelines/offering-help)、[反馈](https://developer.apple.com/design/human-interface-guidelines/feedback)、[警告](https://developer.apple.com/design/human-interface-guidelines/alerts)。

## 2. 四种承载方式

| 类型 | 用途 | 位置与行为 | 例子 |
|---|---|---|---|
| 控件帮助标签 | 回答“这个按钮做什么” | 沿用 macOS 原生 `.help`，指针停留在按钮上时出现；离开后消失 | “添加图片”“选择保存目录” |
| 标题栏短提示 | 一步可学会的技巧，或短暂的操作结果 | 标题与 Pin 按钮之间的空位，单行、不可点击、不抢焦点 | “⌘↵ 存到备忘录”“已存至备忘录” |
| 主动打开的技巧页 | 多步规则、完整快捷键说明 | 在菜单栏图标右键菜单增加“使用技巧…”，打开锚定菜单栏图标的轻量弹出层；关闭后返回原焦点 | 分级全选、列表缩进、保存位置 |
| 需处理的问题 | 权限、保存失败、草稿损坏等需要用户决定的情况 | 维持系统 Sheet / Alert；提供明确的恢复动作 | “允许控制备忘录”“重试保存” |

“Tips”主要指前 3 类。错误不能伪装成会自动消失的教学提示；成功也不需要弹出对话框。Apple 建议帮助标签只解释当前控件，弹出层一次只显示一个，警告框用于重要且需要立即处理的情况：[提供帮助](https://developer.apple.com/design/human-interface-guidelines/offering-help)、[弹出层](https://developer.apple.com/design/human-interface-guidelines/popovers)、[警告](https://developer.apple.com/design/human-interface-guidelines/alerts)。

## 3. 页面布局

```text
┌──────────────────────────────────────────────┐
│ 图标 NotesMate    [标题栏短提示]     Pin  Close │ 40pt
├──────────────────────────────────────────────┤
│ 现在的想法是…                                  │
│                                              │
│             原有正文、选区和滚动区域             │
├──────────────────────────────────────────────┤
│ #  Aa  列表  图片    目录               保存   │ 48pt
└──────────────────────────────────────────────┘
```

- 标题栏短提示使用现有保存成功提示所在的中间区域，不替换 `NotesMate` 标题，也不覆盖 Pin / Close 的 **28 × 28pt** 热区。在 360pt 宽度下可用宽度约 140pt；超出的文案应改写，不靠缩小字号硬塞。
- 标题栏短提示采用 11pt 系统字体、单行、自然居中；文字色沿用 `EditorAppearance.secondary`，成功状态可配一个 12pt 勾选符号。与现有深浅色动态色一致，不另造一套高饱和提示色。
- 技巧页建议宽 **260–300pt**、内容高不超过 **240pt**，最多 4 条；超过时提供“查看全部快捷键”入口，不在弹出层中堆长文。位置由系统按屏幕边界调整。若浮窗处于置顶状态，技巧页仍只出现一层，不与目录菜单或格式菜单叠放。
- 技巧页是用户主动打开的独立帮助表面。其点击应被浮窗外部点击监控识别为同一交互，不应意外关闭尚在编辑的浮窗。关闭技巧页后，把焦点还给此前的编辑器。
- 不在编辑区内增加自动卡片、角标或半透明蒙层；窗口缩到 360 × 200pt 时也维持完整的输入和工具栏区域。

## 4. 触发、时长与优先级

### 自动短提示

仅在**空白草稿、浮窗已聚焦、没有输入法组合输入、没有菜单或 Sheet** 时，允许展示一次功能教学短提示。浮窗打开后等待 **1 秒无输入**再出现，显示 **4 秒**；任何键入、粘贴、拖入、按钮操作、关闭窗口或失焦都会立即撤销。若用户在出现前已开始操作，本次不计为“已看过”，以后仍可在空白状态展示。

每条教学提示每位用户至多自动显示一次；用户完成其对应操作后也标记为已学会。文案版本更新不重置已看状态。用户始终可从“使用技巧…”重新查看，且无需为了看提示清空草稿。

已看和已学会标记存于本机设置，按稳定的提示 ID 记录；不写入笔记正文或草稿文件，也不记录用户输入内容。提示仅在真正显示满 **1 秒**后才算“已看”，打开前被输入打断则保留以后展示的机会。

首个自动提示推荐为 **“⌘↵ 存到备忘录”**。后续功能只在满足明确上下文时入队，例如用户首次创建列表、随后再次打开空白草稿，可展示 **“Tab 增加列表层级”**。不在正在编辑的列表中突然弹出教学内容。

### 状态反馈

保存中沿用标题旁的进度指示，直到操作结束；成功后在标题栏短提示位显示现有文案 **“已保存至系统备忘录”**，维持现有约 **1.2 秒**的短反馈。若保存期间内容未继续变化，现有流程会清空草稿。失败进入带动作的系统对话框，直到用户处理。自动保存草稿不逐次提示；正常每次键入都反馈会打断记录节奏。

同一时刻只显示一条提示，优先级为：**需处理的问题 ＞ 保存中/保存结果 ＞ 用户主动打开的技巧 ＞ 自动教学**。高优先级出现时，低优先级取消而非排队补播；关闭后仍需满足原触发条件才能再出现。菜单、Sheet、图片选择器及输入法候选窗期间，自动教学不出现。

## 5. 文案规则与示例

- 一条短提示只教一个动作，优先写“动作 + 结果”：`⌘↵ 存到备忘录`。中文建议不超过 **12 个汉字宽度**；英文按实际 140pt 槽位验证，不直接按字符数等比翻译。
- 帮助标签以动词开头，说明控件当前动作；Pin 等状态变化时同步改文案。沿用系统 `.help`，避免在旁边再画一个重复的黄色气泡。Apple 对 macOS 帮助标签建议保持简短，并尽量只解释当前控件：[提供帮助](https://developer.apple.com/design/human-interface-guidelines/offering-help)。
- 教学文案统一使用 macOS 键符号 `⌘`、`⌃`、`⇧`、`↵`；第一次出现“备忘录”时可写全名“系统备忘录”，正文不展示内部格式或实现术语。
- 技巧页每条包含短标题和一行解释；不摘录笔记正文、文件夹名或剪贴板内容，也不把这些内容发到系统通知中心。

| 场景 | 标题栏短提示 / 帮助标签 | 技巧页展开说明 |
|---|---|---|
| 快速保存 | `⌘↵ 存到备忘录` | `写完按 ⌘↵，内容存入当前选择的备忘录目录。` |
| 分级全选 | 不自动打断输入；由“使用技巧…”查看 | `连续按 ⌘A：从当前段落、列表项或代码块，逐级扩大到全文。` |
| 列表层级 | `Tab 增加列表层级`，仅符合 §4 的空白状态 | `在列表项按 Tab 缩进，按 ⇧Tab 减少层级。` |
| 保存成功 | `已保存至系统备忘录` | 无需额外解释 |
| 保存失败 | 不使用短提示 | Alert 写明原因，并提供“重试”或权限处理动作 |

## 6. 可访问性与多语言

- 自动短提示不接管键盘焦点；VoiceOver 在提示出现时可读到一次状态变化，取消时不宣布。相同提示不因浮窗反复打开而重复朗读。
- 技巧页可用键盘进入和关闭：从菜单栏菜单打开，`Esc` 关闭；焦点顺序依阅读顺序，关闭后回到先前控件或编辑器。普通帮助标签仍由控件的无障碍名称承担基础说明。
- 尊重“减少动态效果”：提示切换直接淡入/淡出或无动画，不移动正文。深色、浅色和高对比度下文字对比度达到 **4.5:1**；黄色只用于操作强调，不作为唯一的状态信号。
- 中英文文案均通过现有本地化入口维护；按 **360pt 最小宽度**和 macOS 大字号分别验收。未能容纳的短提示应改写或转入技巧页，不允许盖住 Pin / Close。

## 7. 交付验收清单

1. 空白首次打开可看到一条短提示；开始输入、启动输入法、打开任一菜单或缩小窗口时，正文与光标始终可见且可编辑。
2. 同一教学提示自动展示不超过一次；重启 App、置顶、关闭重开窗口均遵守已看状态；“使用技巧…”始终可手动打开。
3. 保存中、保存成功、保存失败不会同时显示；失败信息可处理，不会定时消失。
4. 360 × 200pt、380 × 410pt、中英文、深浅色、窗口贴近屏幕四边分别验收；弹出层不被屏幕裁切，不误触发浮窗自动收起。
5. 键盘、VoiceOver、减少动态效果与高对比度分别验收；Tips 不写入笔记正文或草稿内容。

## 8. 落地顺序

1. 先统一标题栏短提示的状态与优先级，复用已有保存结果区域；保留现有控件 `.help` 和错误对话框。
2. 增加首条自动教学提示，并按 §4 的出现条件和频控验收。未经独立验证的技巧不进入自动队列。
3. 菜单栏“使用技巧…”及轻量技巧页留待后续讨论；当前不改菜单栏弹层。
